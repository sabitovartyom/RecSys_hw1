# Домашнее задание 1: top-10 рекомендации

**ФИО:** Сабитов Артём Андреевич.

**Датасет:** [Amazon Review Data 2018 — Musical Instruments](https://cseweb.ucsd.edu/~jmcauley/datasets/amazon_v2/index.html),
5-core и метаданные товаров.

Установите зависимости из `requirements.txt`, откройте `experiments.ipynb` в Jupyter
и выполните все ячейки. Данные загружаются автоматически. Результаты, графики,
выбранные настройки и выводы сохранены в notebook; дополнительные CSV создаются в `results/`.

Модели находятся в `models/`, подготовка данных — в `data.py`,
общая оценка — в `evaluation.py`, циклы экспериментов — в `experiment.py`.
